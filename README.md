## 🛠️ How to Customize Projects & Renders

1. Save your renders or drawings in `atelier-portfolio/assets/`.
2. Open `atelier-portfolio/js/main.js` and edit `KB_PROJECTS`:
   ```javascript
   {
     id: 'my-custom-project',
     title: 'Project Title',
     sizeContext: '1,850 m² • 4 Levels • 32m × 24m Footprint',
     slides: [
       { url: 'assets/my-render-1.jpg', caption: 'Slide 01 // Master Exterior Elevation' },
       // ... up to 5 slides
     ]
   }
   ```

## 🌍 Free 1-Click Hosting & Deployment

This portfolio is statically optimized for zero-dependency high-speed hosting:

### Option 1: GitHub Pages (Recommended — 100% Free)
1. Go to your repository on GitHub: `https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPOSITORY_NAME>`.
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your portfolio will be live at `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPOSITORY_NAME>/` in seconds.

### Option 2: Vercel
1. Import the GitHub repository at [vercel.com/new](https://vercel.com/new).
2. Framework Preset: **Other** / Root Directory: `./`.
3. Click **Deploy**.

### Option 3: Netlify
1. Connect repository at [app.netlify.com](https://app.netlify.com).
2. Build command: *(leave empty)* / Publish directory: `.`.
3. Click **Deploy Site**.
